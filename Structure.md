# Архитектура проекта light3D

## Описание
Легкий 3D-редактор с интуитивным управлением в стиле Roblox Studio на базе движка Bevy (Rust).

## Структура файлов

- `Cargo.toml` — Зависимости и конфигурация сборки проекта.
- `Structure.md` — Карта и архитектурное описание проекта.
- `assets/` — Статические ресурсы редактора.
  - `icons/`
    - `add.png` — Иконка кнопки создания проекта.
- `src/`
  - `main.rs` — Точка входа в программу, инициализация приложения и базовых плагинов Bevy.
  - `project_manager.rs` — Логика работы с файловой системой (папка проектов, чтение/создание проектов).
  - `editor/`
    - `mod.rs` — Модуль 3D-редактора.
    - `camera.rs` — Управление камерой редактора.
  - `ui/`
    - `mod.rs` — Модуль интерфейса.
    - `hub.rs` — Экран приветствия (список проектов, создание нового).
    - `editor_ui.rs` — Интерфейс инструментов редактора.
